# 估價項目顯示／計價勾選設計

## 目的

讓使用者暫時停用已輸入的估價項目，而不必刪除並重新輸入。重新勾選後，原項目的區域、文字、數量、單位、單價與備註必須完整恢復。

## 行為

- 所有新建施工項目預設為勾選，輸入資料後自動正常顯示及計價。
- 每個施工項目前方提供「顯示／計價」勾選框。
- 取消勾選只改變啟用狀態，不清空或刪除任何欄位；編輯列保留在原工種及原區域並以淡化樣式呈現。
- 暫停項目不列入工種小計、右側總額、管理費、稅額、APP 估價明細、文字摘要、PDF、ODS及施工備註。
- 重新勾選立即使用原資料恢復計價與全部輸出。
- 舊草稿中沒有啟用欄位的項目視為已勾選，確保既有估價內容不會消失。
- 適用工種：櫃體、木作、地板、土水、保護、清運、水電、油漆、空調與自訂工程。

## 實作選擇

採用各項目資料內的 `enabled` 狀態，未設定時等同 `true`。計算與輸出共用同一判斷，避免畫面總額與 PDF／ODS 不一致。清運目前是單一項目，使用獨立但同規則的啟用狀態。

未採用獨立「隱藏項目」區，因為會把項目移離原工種與區域，增加尋找和恢復操作。

## 限制與防錯

- 取消勾選不是刪除，原有刪除按鈕仍保留並維持原行為。
- 勾選狀態跟隨本機草稿與草稿備份／匯入保存。
- 付款階段、發票與工程管理費不屬於施工項目，不新增此勾選框。
